## 2026-10-17

### 决策 24：基础设施与计算层全面落地
**内容**：GMRE 底层数据与计算基座完成建设，不碰 `engines_v3` 引擎代码，严格遵守 30 天窗口纪律。
1. **历史序列库** (`series_history`)：入库 60 年宏观数据（10Y/2Y/CPI等），HY 系列拉取受限保留 3 年数据。
2. **分位计算层** (`series_percentile`)：算出现有指标的 1y/5y 分位与 z-score。
3. **治理层** (`event_calendar` / `check_freshness`)：录入未来 2 个月关键宏观事件，建立数据新鲜度 SLA 检查。
4. **RRP 数据修复**：发现历史库中存入的是滞后的 FRED 数据，已删除并替换为 NYFed 的实时 `RRP_NYFED`。
5. **飞书展示层**：修复 `fred_macro.py` 的 `.env` 加载问题，成功将 `USDJPY` 纳入推送。

**关键分位发现（10-17 基线）**：
- **CPI 5y_pct = 100.0%**（通胀历史最高位）
- **HY_CCC 5y_pct = 99.9%**（信用风险极值）
- **10Y / 30Y 5y_pct = 99.1%**（利率极值）
- **VIX 5y_pct = 38.5%**（波动率依然低位）
**结论**：系统用数据量化确认了“利率+信用极值 vs 波动率低位”的历史级背离。
